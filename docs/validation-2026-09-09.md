## 已完成

- Gate、planner、worker 默认继承 Pi 当前模型，复用 Pi 认证；基准使用 Pi SDK，不再单独直连 OpenRouter。明确配置的模型必须存在且已认证，不静默切换供应商。
- Worker 启动前解析模型；integration fixer 仅能修改参与任务已授权的路径，并在提交前检查实际 diff。
- 报告依据任务、candidate 和最终集成的真实检查生成结论；跳过或缺失验证不能报告完整成功。最终验证持久化，PR 目标、命令与路径统一脱敏。
- 基准按案例和尝试分别统计，保留首次失败及累计成本，记录模型、配置、源码哈希，拒绝跨快照覆盖重试。
- 规划调用增加实际中止信号；关闭推理时不发送字符串 `off`。输出到达上限单独报错，不进入相同上限的 JSON 修复循环。

**OAuth 定点复测仍失败。** 最终代码使用同一模型和同一合成任务，将输出上限改为 32K、单次截止时间改为 240 秒，关闭 schema 修复重试，只进行一次调用。模型在 182.5 秒后正常停止，返回 5,557 字符的最终文本，但 `docs_worker.acceptance.commands` 含不安全 shell 语法，计划校验拒绝了结果。估算费用 $0.029403384。该调用没有执行模型生成的命令，也未并入初跑成绩。

这说明复杂规划的问题不只在输出额度；增加额度不能替代计划有效性检查。本次不据此宣称规划质量已改善。详见[独立复测记录](./evidence/v0.11.0/oauth-targeted.json)。

## 本地使用

在工作区执行 `pi -e ./index.ts` 加载这一版本，在 Pi 中选择 `deepseek/deepseek-v4-flash`，然后使用 `/capstan "任务"`。认证在 Pi 中配置，Capstan 不另存 API 密钥。
